# V2G通信点表

逻辑地址 N = 本表「寄存器地址」= RTU 报文 PDU。  
mbserver 6 位显示 = **400001 + N**（401002 = 1001，401029 = 1028）。  
R = 只读状态；R/W = 控制，网关只允许写这些地址。

JSON 名称列与现网 `eeg/.../charger/ch001/status` 字段一致。`registers` 通道的键仍是逻辑地址字符串（`"1001"`），不是本列名称。未进入 `status` 的点仅出现在 `registers`，本列给出拟定业务键，便于后续补进 status。
