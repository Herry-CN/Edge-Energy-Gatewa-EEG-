# Modbus 设备模型规范 V2
> 本版本仅修复重复表达与逻辑冲突,不扩展新功能。

## 1. 文档定位(收敛 M4)
本规范是**寄存器字段语义的唯一权威来源(SSOT)**。
- 地址来源:RS485与V2G充电桩通信点表
- 上层引用:STM32 架构设计 / MQTT 通信协议 均引用本规范,不重复定义。

## 2. 通用约定(收敛 M2)
| 项 | 规则 |
|---|---|
| 数据类型 | 16-bit 无符号(除特别标注) |
| 功率换算 | 工程值(kW) = 原始值 / 10 |
| SOC 换算 | 工程值(%) = 原始值 / 10 |
| 字节序 | 大端(Modbus 标准) |
| 组合字段 | **未经厂家确认不得拆位解释(M3)** |

## 3. 寄存器语义分类表(核心修复 M1)
> 一址一义,严禁跨类混用。

### 3.1 标识 / 信息类
| 地址 | 名称 | 语义来源 |
|---|---|---|
| 1001 | 设备标识/信息字 | 以本规范定义为准,**禁止解释为运行状态** |

### 3.2 状态类(只读)
| 地址 | 名称 | 说明 |
|---|---|---|
| 1002-1011 | 运行/电气量状态 | 只读遥测 |
| 1034 | **状态枚举**(独立寄存器) | 与 1050 无关 |

### 3.3 遥测 / 电气量类(只读)
| 地址 | 名称 | 换算 |
|---|---|---|
| 1023 | 组合状态字 | 不拆位(M3) |
| 1026 | 组合状态字 | 不拆位(M3) |
| 1027 | 待确认量 | **单位需厂家确认**,确认前不作为功率工程值上报 |
| 1028-1033、1035、1037、1039-1042 | 电气/环境遥测 | 按 §2 换算 |

### 3.4 设定 / 控制类(可写白名单)
| 地址 | 名称 | 换算 | 备注 |
|---|---|---|---|
| 1021 | 离线最大放电功率 | kW×10 | |
| 1022 | 离线最大充电功率 | kW×10 | |
| 1024 | 充电功率设定 | kW×10 | |
| 1025 | 放电功率设定 | kW×10 | |
| 1048 | 目标 SOC | %×10 | |
| 1049 | 工作模式 | chg/v2g 枚举 | |
| 1050 | **控制寄存器** | raw 写入 | 点表未定义具体写值;start/stop 映射**需厂家确认(M1)** |

## 4. 语义边界硬约束
- 1001 ≠ 运行状态
- 1034(状态枚举) ≠ 1050(控制寄存器),为两个独立地址
- 组合字段(1023/1026)不得擅自拆位
- 1027 未确认单位前不得当作功率工程值

## 5. 有效地址全集(与点表一致)
1001-1011、1021-1035、1037、1039-1042、1048-1050
